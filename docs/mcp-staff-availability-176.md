# MCP スタッフ割当候補（#176）

`list_staff_availability` は、最大24時間のタイムゾーン付き日時と事業所を指定し、スタッフごとのシフト重複と、指定した利用者への担当登録を返す。終了時刻と次の開始時刻が一致する場合は重複しない。取消・論理削除済みシフトは対象外。区間担当は区間の時間で判定し、区間のない旧形式の担当はシフト全体で判定する。割当やシフトを変更しない。

シフトと人物検索の双方の事業所設定が有効で、シフト閲覧が全件の利用者だけが利用できる。部分的な閲覧範囲では重複なしを正確に判定できないため拒否する。勤務予定・休暇、移動時間、資格、担当条件の適合は判定できず、重複なしでも要確認とする。担当登録の有無は適合性や勤務可能性を保証しない。

Context7 は利用枠上限のため、2026-10-29 に Supabase公式の [DB関数](https://supabase.com/docs/guides/database/functions)・[RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) を確認した。実環境への migration・MCP関数配備、実認証試験、機能有効化は別途必要。
