# Google Workspace Essential Starter 導入提案

作成日: 2026-06-25

## 提案の目的

事業所のスタッフ向けに、Google Workspace Essential Starter を導入し、以下を実現します。

- **統一的なアカウント管理** — @shoug.org ドメインのメールアドレス（オプション）
- **カレンダー共有** — スタッフ勤務表、会議スケジュール管理
- **ドライブ共有** — 共有フォルダ、ドキュメント管理
- **セキュリティ・アクセス制御** — ドメイン単位でのユーザー管理

本提案では、**メール不要**で、カレンダー・ドライブ・アカウント管理に特化した導入を想定しています。

## Google Workspace Essential Starter とは

| 機能 | Essential Starter | 他プラン |
|---|---|---|
| **Gmail** | ❌ なし | Pro（$12/月） |
| **Google カレンダー** | ✓ あり | ✓ あり |
| **Google ドライブ** | ✓ あり（30GB） | ✓ あり |
| **Google Meet** | ✓ あり（150分） | ✓ あり（24時間） |
| **Google Docs/Sheets** | ✓ あり | ✓ あり |
| **セキュリティ機能** | ✓ あり | ✓ あり（拡張） |
| **管理コンソール** | ✓ あり | ✓ あり |
| **料金** | $6/user/月 | $12/月以上 |

**Essential Starter は「メール不要、基本機能あれば」という事業所に最適。**

## 導入の利点

### 1. カレンダー統合（勤務シフト・会議管理）

```
スタッフA:  (他のツール)  → Google カレンダー へ一元化
スタッフB:  (Outlook等)   ↓
スタッフC:  (個人メール)  ← 施設全体で共有可能
```

- **勤務シフト管理** — 誰がいつ勤務するかを一覧表示
- **会議スケジュール** — 施設内会議、研修スケジュール
- **時間帯の見える化** — Care Record の提供時間と連携？（将来）

### 2. ドライブ共有（ファイル・ドキュメント管理）

```
/施設共有ドライブ/
├─ /マニュアル → 業務マニュアル、研修資料
├─ /帳票 → 月間報告書、提出書類テンプレート
├─ /議事録 → 会議議事録アーカイブ
└─ /その他
```

- **バージョン管理** — 複数人が編集しても衝突しない
- **アクセス権限** — 部門別・役職別の アクセス制限
- **監査ログ** — 誰がいつ編集したか、削除したか記録

### 3. セキュリティ・アクセス制限

- **ドメイン内のみアクセス可能** — 外部への データ流出防止
- **2 段階認証対応** — パスワード + スマホ認証
- **監査ログ** — すべてのアクティビティを記録（コンプライアンス）

## セットアップ手順

### Phase 1：Google Workspace 契約（1日）

1. **Google Workspace へアクセス**
   - https://workspace.google.com

2. **Essential Starter プランを選択**
   - ユーザー数：実数 + 2-3（追加採用対応）
   - 初期ユーザー数 10 人の場合：$60/月

3. **ドメイン確認**
   - shoug.org の所有確認（DNS TXT レコード追加）
   - 確認完了後、ドメイン有効化

### Phase 2：ユーザーセットアップ（1-2週）

#### 2-1. ユーザーアカウント作成

Google Workspace 管理画面で、スタッフ情報を登録：

```
姓名: 安部 太郎
メール: taro.abe@shoug.org
部門: 訪問介護
役職: 訪問介護士
```

### 2-2. 初期パスワード設定

各ユーザーへ初期パスワードをメール送付（またはリセットリンク）。初回ログイン時に変更を強制。

### 2-3. 2段階認証の有効化（推奨）

```
設定 → セキュリティ → 2段階認証を有効化
確認方法: スマートフォンの Google Authenticator または SMS
```

### Phase 3：共有フォルダ・カレンダー構築（1週）

#### 3-1. 共有ドライブ作成

Google ドライブ内で：

```
共有ドライブ「施設運用」
├─ /マニュアル
├─ /帳票
├─ /議事録
└─ /その他
```

アクセス権限：

```
オーナー: 管理者アカウント（admin@shoug.org）
編集者: 部門長、スタッフ代表
閲覧者: 全スタッフ
```

#### 3-2. 施設カレンダー作成

Google カレンダー内で：

```
カレンダー「施設勤務シフト」
カレンダー「会議・研修」
カレンダー「施設休業」
```

各スタッフのカレンダーに追加し、共有化。

### Phase 4：運用開始（継続）

1. **毎月のユーザー管理**
   - 新規スタッフ: アカウント作成
   - 退職スタッフ: アカウント無効化

2. **セキュリティ監視**
   - 管理コンソールでログイン監査ログを確認
   - 異常ログインの検知

## トラブルシューティング

### ログインできない

**症状：** メールアドレス/パスワード入力後、アクセス拒否

**対処：**
1. 初期パスワードではなく、「パスワードをリセット」から新規設定
2. Caps Lock やキーボード言語が正しいか確認
3. 管理者に連絡（アカウントロックされていないか確認）

### 2段階認証コードが出ない

**症状：** Authenticator アプリにコードが表示されない

**対処：**
1. スマートフォンの時刻がズレていないか確認
2. Authenticator アプリを再インストール
3. バックアップコードを使用（管理者に依頼）

### ドライブが同期されない

**症状：** パソコンの Google ドライブフォルダが同期されない

**対処：**
1. Google Drive for Desktop を再起動
2. ネットワーク接続を確認
3. キャッシュをクリア
