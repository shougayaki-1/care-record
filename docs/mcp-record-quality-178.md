# MCP 提供記録の確認（#178）

`check_record_quality` は指定した記録について、現在の利用者フォームの必須項目、サービス提供時間、担当者、交通費、記録日時を確認し、利用可能な対応シフトの日時・利用者との差を要確認として返します。既存の候補検証を利用してフォームの型と選択肢も確認します。記録やシフトは更新しません。

DB は OAuth、事業所と記録の閲覧権限・機能設定を検証します。シフトは別途、シフト閲覧の設定と対象への権限を満たした場合のみ参照し、見られない場合は比較不能とします。複数シフト、取消、サービス区間の欠落や日時差は確認を促し、過去のフォーム、月跨ぎなどを自動的に正しいと断定しません。表示項目は利用時点のフォームであり、記録当時のフォームの証明ではありません。

Context7 は利用枠上限のため、2026-10-29 に Supabase の [DB 関数](https://supabase.com/docs/guides/database/functions)・[CLI](https://supabase.com/docs/reference/cli/supabase-db-push) 公式資料を参照しました。MCP 関数の配備、実認証試験、事業所の機能有効化は別途必要です。
