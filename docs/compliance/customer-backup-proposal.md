# 事業所向け提案書: 提供記録バックアップと即時提示体制

作成日: 2026-06-25

## この提案書の目的

この提案書は、提供記録データを安全に保管しつつ、万一本番システムが停止していても実地指導時に必要な記録を短時間で提示できる体制を整えるための提案です。

想定する読み手は、以下の両方です。

- 経営者: 何を守るのか、いくらかかるのか、どこまで備えるのかを判断する
- IT担当者: どのクラウドに、どのデータを、どの期間、どの方式で保存するかを設計する

## 結論

推奨構成は Google Cloud Storage を使った二層構成です。

- 即時提示用: 東京リージョンの Standard ストレージに直近 90 日分の検索用エクスポートを保存
- 長期保全用: 東京リージョンの Archive ストレージに月次確定版を 7 年保存
- 改ざん防止: Archive 側は Bucket Lock を使い、保存期間中は削除・短縮できないようにする

この構成にすると、普段の検索は速く、長期保存の料金は非常に低く抑えられます。画像を保存対象に含めない前提では、保存コストは小さく、主な論点は運用設計と保存年限です。

## 保存対象

今回の提案では、画像や写真は対象外とし、提供記録表のデータだけを保存対象にします。

保存対象は次のとおりです。

- 提供記録の固定項目
  - 利用者名
  - 記録日
  - サービス開始・終了日時
  - 担当者
  - 提供時間
  - 移動時間
  - 承認状態
  - 削除状態
- 提供記録の可変項目
  - 記録フォームの本文
  - 加算や備考
  - テンプレートごとの入力項目
- 検索用索引
  - 利用者名
  - 日付
  - 状態
  - 出力日時

## 保存場所と保存期間

| データ | 主な用途 | 保存場所 | 保存クラス | 保存期間 | 特徴 |
|---|---|---|---|---|---|
| 日次検索用エクスポート | 実地指導、障害時の即時提示 | Google Cloud Storage 東京 | Standard | 90日 | 取得料金なし。日常的に開きやすい |
| 月次確定エクスポート | 長期保全、監査、事故対応 | Google Cloud Storage 東京 | Archive | 7年を推奨 | 低コスト。取り出しはミリ秒単位だが、取得料金あり |
| 復旧用設定情報 | 障害復旧 | 別管理の安全な保管先 | Standard または Nearline | 1年 | 環境変数名、Migration、運用手順など |

補足:

- 7年は事業運営上の保守的な提案値です。法令・契約・サービス種別ごとに最終確定してください
- 日次検索用エクスポートは「検索して提示するため」のデータです
- 月次確定エクスポートは「消せない保全データ」です

## 料金の目安

以下は Google Cloud Storage 東京リージョンの公開価格をもとにした、ストレージ料金の目安です。税金、為替、通信料、開発費は含みません。

### ストレージ単価の目安

| 保存クラス | 単価の目安 | 最低保存期間 | 取得料金 | 向いている用途 |
|---|---|---|---|---|
| Standard | 約 $0.02 / GB / 月 | なし | なし | すぐ開く検索用データ |
| Nearline | 約 $0.01 / GB / 月 | 30日 | $0.01 / GB | たまに参照する予備保管 |
| Coldline | 約 $0.004 / GB / 月 | 90日 | $0.02 / GB | 四半期単位の参照 |
| Archive | 約 $0.0012 / GB / 月 | 365日 | $0.05 / GB | 長期保全、監査、法定保管 |

### 保存容量ごとの月額イメージ

以下は単純化のため、総保存量をそのまま各クラスに置いた場合の目安です。

| 総保存量 | Standard | Archive |
|---|---|---|
| 10GB | 約 $0.20 / 月 | 約 $0.01 / 月 |
| 100GB | 約 $2.00 / 月 | 約 $0.12 / 月 |
| 500GB | 約 $10.00 / 月 | 約 $0.60 / 月 |

### 推奨構成での月額イメージ

以下は、総保存量のうち 10% を Standard、90% を Archive に置いた場合の概算です。

| 総保存量 | 推奨構成の月額目安 |
|---|---|
| 10GB | 約 $0.03 / 月 |
| 100GB | 約 $0.31 / 月 |
| 500GB | 約 $1.54 / 月 |

### 取り出し時の目安

Google Cloud Storage は Archive でもオフライン復元待ちがなく、すぐ読み出せます。ただし、保存クラスに応じた取得料金がかかります。

| 取り出し量 | Standard | Archive |
|---|---|---|
| 1GB | $0 | 約 $0.05 |
| 10GB | $0 | 約 $0.50 |
| 50GB | $0 | 約 $2.50 |

この用途では、実地指導時の検索対象を直近 90 日分の Standard に寄せるため、通常の提示業務で取得料金が大きくなる可能性は低い想定です。

## 特徴

### 経営者向けの見方

- 本番停止時でも、提供記録を別保管先から提示できる
- 画像を含めないため、月額費用は比較的軽い
- 長期保管データは改ざん防止をかけられる
- 実地指導や監査のたびに「復元作業」をしなくてよい

### IT担当者向けの見方

- GCP Archive は低コストでもオンラインで、ミリ秒単位で読み出せる
- Standard は取得料金がないため、検索用データの常置先として扱いやすい
- Bucket Lock により保存期間の短縮や削除を防げる
- ライフサイクル管理で Standard から Archive への移行を自動化できる

## AWS を選ぶ場合の比較

AWS でも同等構成は可能です。主な対応関係は以下です。

| Google Cloud | AWS | 特徴 |
|---|---|---|
| Standard | S3 Standard-IA または S3 Standard | すぐ開ける保管先 |
| Archive | S3 Glacier Instant Retrieval または S3 Glacier Flexible Retrieval | 長期保管向け |
| Bucket Lock | S3 Object Lock | 改ざん防止、保存期間固定 |

ただし、AWS は保存クラスの選び方に少し注意が必要です。

- S3 Standard-IA はミリ秒アクセスだが取得料金がある
- S3 Glacier Instant Retrieval も即時取得だが 90 日の最低保存期間がある
- S3 Glacier Flexible Retrieval は分単位から時間単位の復元待ちがあり、即時提示用途の主保管先には向きにくい
- S3 Object Lock は Versioning を前提に WORM 保管を行う

本提案の要件では、即時提示と長期保全を両立しやすいのは GCP のほうです。AWS は既存の社内標準や契約都合がある場合の代替候補と考えるのが自然です。

## 推奨運用

1. 毎日1回、提供記録データを CSV または JSON で出力する
2. 直近 90 日分を Standard に置き、検索用索引と一緒に保存する
3. 月次確定版を Archive に送り、7 年保管する
4. Archive 側は Bucket Lock を設定する
5. 月1回、実際に 10 分以内に取り出せるか訓練する

## 提案の判断ポイント

- まず必要なのは「バックアップ」より「提示できる退避データ」です
- 画像を除くため、料金は小さく抑えやすいです
- 7 年保存は経営上は安心ですが、最終的には法令・契約の確認が必要です
- 事業所向け説明としては、月額数百円未満から数ドル程度で始められる可能性があります
