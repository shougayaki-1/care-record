# MCP 提供記録の参照（#174）

`list_records` は事業所・JSTのサービス日（両端含む、最大366日）、任意の利用者・スタッフID、状態で検索する。最大100件、offset方式で `has_more` を返す。状態と現在の版を含むが本文は一覧に含めない。`get_record` は記録IDで本文・承認状態・現在の版と添付件数を返す。画像や保存パスは公開しない。存在しない記録と権限外の記録はともに null。

両RPCはOAuth有効性、事業所所属、事業所別の独立した既定off設定、既存の記録閲覧権限と担当利用者の範囲を確認する。管理権限と提供条件6項目を確認して有効化でき、設定変更と監査は同一トランザクション。RLSとpermissionsは変更していない。入力・出力・例外本文を運用ログへ記録しない。

外部AIの提供条件は未確認であり、実データへの機能有効化は未承認。migration、MCP関数配備、実認証確認は別途実施する。
