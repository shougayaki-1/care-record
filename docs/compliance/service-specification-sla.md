# サービス仕様適合開示書・SLAひな形

契約ごとに空欄を埋め、顧客と明示合意します。公開サイトの一般規約だけで代替しません。

## サービスとデータ

- 対象機能、利用者、扱う医療・介護情報、法定保存対象：`要記入`
- 構成図・データフロー・API・外部出力：`要添付`
- 保存・処理国、国外法適用可能性：`vendor_registry参照`
- Supabase、Vercel、Google、検査・監査保全サービスと再委託先：`要記入`

## 責任分界

CareRecordはアプリ、クラウド設定、監視、バックアップ、脆弱性、事故連絡を担当します。利用事業所はアカウント申請・失効、管理端末、施設ネットワーク、PDF等の持出し、職員教育を担当します。保持、権限、監査、事故対応は共同で決定します。

## SLA

- 月間可用性：`要合意`
- 計画停止通知：`要合意`
- RPO/RTO：暫定60分／8時間、契約前に確定
- Critical事故第一報：検知後`要合意`時間以内
- 問合せ・障害の受付時間、応答・復旧目標：`要合意`
- ログ、バックアップ、記録の保持期間：`要合意`
- 監査資料、脆弱性、再委託変更の通知方法：`要合意`

## 終了・移行

返却形式、見読性、移行支援、返却期限、通常・バックアップ・外部連携先の消去期限、消去証明、法令上保持が必要な例外を定めます。顧客は契約期間中にデータをエクスポートでき、運営者の都合で利用不能にしません。
