プライバシーポリシー

CareRecord（以下，「当社」といいます。）は，本ウェブサイト上で提供するサービス（以下，「本サービス」といいます。）におけるユーザーの個人情報の取扱いについて，以下のとおりプライバシーポリシー（以下，「本ポリシー」といいます。）を定めます。

第1条（収集する情報）

当社は、本サービスの利用にあたり、以下の情報を取得する場合があります。

  • アカウント情報：氏名、メールアドレス、プロフィール画像（Google/Microsoftアカウント連携時）
  • サービス利用情報：訪問介護記録データ、ログデータ、利用日時
  • Googleカレンダー連携情報：連携先カレンダーの識別子、予定の識別子と同期状態、Googleから取得した連携先カレンダーの情報および予定情報

第2条（利用目的）

当社が個人情報を収集・利用する目的は，以下のとおりです。

  • 本サービスの利用登録、本人確認、認証のため
  • 訪問介護記録の作成、保存、管理および出力のため
  • 事業所のシフト予定をGoogleカレンダーへ登録・更新・削除し、同期状態を確認・修復するため
  • 本サービスの維持、改善、不正利用の防止のため
  • ユーザーからのお問い合わせに対応するため

第3条（Googleユーザーデータの取扱い）

Googleアカウントでのログイン時には氏名、メールアドレス、プロフィール画像を取得します。事業所の管理者がGoogleカレンダー連携を許可した場合には、そのアカウントに事業所用のカレンダーを作成し、連携先カレンダーの情報と予定を取得します。シフトの件名・日時・キャンセル理由などをGoogleカレンダーの予定として登録・更新します。件名には利用者名や担当スタッフ名が含まれる場合があります。シフトの変更・削除や同期修復に合わせて予定を更新・削除します。

  • 利用の制限：Googleアカウント情報はログイン・本人確認に、カレンダー情報は事業所のシフト同期と同期修復に使用します。広告配信や第三者への販売には使用しません。
  • 保存と保護：Googleの更新トークンは暗号化して保存し、カレンダーと予定の識別子、同期状態をデータベースに保存します。シフト予定は、連携を許可したGoogleアカウントのカレンダーにも保存されます。
  • 連携の解除：連携を解除すると、本サービスに保存した更新トークンを破棄し、以降の同期を停止します。すでにGoogleカレンダーに作成されたカレンダーや予定は残るため、必要に応じてGoogleカレンダー側で削除してください。
  • 第三者提供の禁止：法令に基づく場合を除き、ユーザーの同意なくGoogleユーザーデータを第三者に提供、販売、共有することはありません。
  • AIモデルへの使用禁止：Googleユーザーデータを、AI（人工知能）モデルのトレーニングに使用することはありません。

本サービスのGoogle APIからの情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）を遵守します。

第4条（個人情報の管理）

当社は、ユーザーの個人情報を正確かつ最新の状態に保ち、個人情報への不正アクセス・紛失・破損・改ざん・漏洩などを防止するため、セキュリティシステムの維持・管理体制の整備等の必要な措置を講じます。

第4条の2（要配慮個人情報・委託先・国外での取扱い）

本サービスで取り扱う訪問介護記録等には、病歴、心身の状態その他の要配慮個人情報が含まれる場合があります。当社は、サービス提供に必要な範囲で、クラウド基盤、認証、ホスティング、Google連携、セキュリティ検査等の事業者へ取扱いを委託することがあります。委託・再委託先、保存・処理国、安全管理措置は、契約時のサービス仕様適合開示書で利用事業所へ提示します。国外で取り扱う場合は、適用法令に従い必要な情報提供その他の措置を行います。

第5条（個人情報の第三者提供）

当社は，次に掲げる場合を除いて，あらかじめユーザーの同意を得ることなく，第三者に個人情報を提供することはありません。

  1. 法令に基づく場合
  2. 人の生命，身体または財産の保護のために必要がある場合
  3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合

第6条（データの削除・退会）

ユーザーは、本サービスの設定画面または下記のお問い合わせ窓口を通じて、自身のアカウントおよび関連する個人情報の開示、訂正、利用停止または削除を請求できます。ただし、法令、利用事業所との契約、事故調査または権利保全のため保持が必要な情報は、目的を限定しアクセスを制限して必要期間保持します。記録種別ごとの保存期間、契約終了時の返却形式および消去期限は利用事業所との契約で定めます。

第6条の2（安全管理と事故対応）

当社は、アクセス制御、暗号化、操作記録、バックアップ、脆弱性管理、委託先管理、教育および非常時手順を含む安全管理措置を講じます。漏えい等が発生した場合は、影響を調査・封じ込め、個人情報保護委員会その他の関係機関への報告および本人・利用事業所への通知を、法令および契約に従って行います。

第6条の3（本ポリシーの変更）

重要な変更を行う場合は、施行日と変更内容を本サービス内その他の適切な方法で通知し、法令または契約上必要な場合は改めて同意を取得します。変更履歴は保存します。
