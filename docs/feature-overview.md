# 機能一覧（src/app/app/ 配下）

認証後アプリのページ単位の概要。詳細な挙動は各ディレクトリのコードを正とする。

| ディレクトリ | 画面/機能 | 概要 |
|---|---|---|
| `record/` | 記録を作成 | 訪問介護の記録作成（`[clientId]` で利用者別）。AI取込結果の反映先でもある |
| `shifts/` | シフト管理 | シフトの作成・編集、Googleカレンダー同期（docs/architecture.md参照） |
| `reports/` | 帳票・レポート | 記録・シフトを束ねた帳票生成（`reportShifts.ts`でシフト紐付け） |
| `clients/` | 利用者管理 | 利用者（`[id]`で個別）の登録・編集 |
| `staff/` | スタッフ(名簿)管理 | 職員名簿の管理 |
| `statistics/` | 統計 | 労務・稼働等の集計表示 |
| `ai-import/` | AI取込 | Vertex AI Geminiによる記録の自動抽出とレビュー・確定 |
| `internal-work/` | 内勤を記録 | 訪問以外の内勤業務の記録 |
| `backup/` | バックアップ閲覧 | GCSに保存したバックアップの閲覧 |
| `logs/` | ログ | 操作・監査ログの閲覧（フィルタ・CSVエクスポート） |
| `accounts/` | アカウント・権限管理 | ユーザーアカウントとロール割当の管理 |
| `settings/` | 設定 | 組織設定、`settings/roles`でロール（権限プリセット）編集 |
| `history/` | 履歴 | シフト/記録の時系列履歴表示 |
| `profile/` | アカウント設定 | ログイン中ユーザー自身の設定 |

`src/app/super-admin/` はテナント横断のシステム管理者向け画面（通常の組織ユーザーはアクセス不可）。
`src/app/join/` と `src/app/setup/` は招待受諾・初期セットアップのオンボーディングフロー。
