# 利用事業所向け運用規程テンプレート

- アカウントは個人単位で申請・承認し、異動・退職日に失効する。共有は禁止する。
- 管理端末はサポート中OS、画面ロック、ディスク暗号化、EDR、更新、遠隔消去を必須とする。
- 私物端末、私物クラウド、私物メールへの医療情報保存を禁止する。
- PDF・印刷・ダウンロードは業務上必要な最小限にし、持出し、受渡し、返却、消去を記録する。
- 権限と監査ログを四半期・月次で確認し、不審操作を直ちに報告する。
- 停止時は承認済み代替様式を使い、復旧後の転記で作成者・転記者・各時刻を残す。
- フィッシング、誤送信、紛失、マルウェア、不審ログインは自己判断で隠さず直ちに連絡する。
- CareRecordと事業所の責任分界、SLA、保持、事故連絡を契約時と変更時に再確認する。
